💰 Sobre o Projeto
Aplicação em Python executada via terminal que realiza uma consulta financeira mensal. O sistema permite que o usuário informe sua renda e detalhe duas despesas (incluindo categoria e valor). A partir dessas entradas, o programa calcula o total gasto, exibe o saldo remanescente e fornece um diagnóstico sobre a situação financeira do mês.
